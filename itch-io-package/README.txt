# New H.E.R.O.

Recreation of the classic ATARI H.E.R.O. game, developed with TypeScript

## 🎮 Cómo jugar

- **Flechas del teclado** o **WASD**: Mover al personaje
- **Espacio**: Usar el jetpack
- **P**: Pausar el juego
- **M**: Silenciar/Activar música

## 🛠️ Tecnologías

- TypeScript
- JavaScript
- HTML5
- CSS3

## 📱 Plataformas

- Web (HTML5)
- Mobile
